# Pocket OpenCode — Android

Версия 0.4.9 исправляет упаковку npm: каталоги `__generated__` теперь сохраняются в APK. Во встроенной среде доступны `opencode`, `npm`, `npx` и `curl` на PATH. CLI-запускатели установлены Android вместе с APK; они передают аргументы встроенным Bun/Node, сохраняя рабочий каталог и код завершения. Ограничения Android на сторонние нативные бинарники остаются прежними.

Для подготовки runtime из исходников дополнительно нужен Android NDK (проверен r29): задайте `ANDROID_NDK_HOME` перед `node scripts/prepare-runtime.mjs`. Только запускатели можно пересобрать командой `node scripts/prepare-launchers.mjs`. NDK нужен на компьютере для сборки, на телефоне он не требуется.

Неофициальное Android-приложение с локальным OpenCode. ПК, root и Termux не требуются для встроенного режима. Модель подключается через интернет/API.

## Что внутри

- Родной GUI OpenCode (`packages/app` и `packages/ui`, версия 1.18.31) внутри Android WebView. HTML, JavaScript, стили, шрифты и иконки включены в APK. Чат, модели, настройки и просмотр изменений — компоненты самого OpenCode.
- Дополнительный экран **Android** для импорта/экспорта ZIP, Git и управления встроенной средой.
- OpenCode 1.18.31 и официальный Bun Android 1.4.2. Приложение использует существующий HTTP API OpenCode: сессии, провайдеры, модели, разрешения и вопросы агента.
- Встроенные Git, Node.js, ripgrep и npm. Инструменты выполняются в приватном каталоге приложения.
- Создание проектов, клонирование публичных HTTPS-репозиториев, импорт и экспорт ZIP через системный выбор файлов.
- Редактор текстовых файлов до 1 МБ, просмотр изменений агента, остановка задачи, история диалогов.
- Автоматический приоритет Termux на **этом же телефоне**: при наличии совместимого Termux ядро, чтение/запись файлов и инструменты агента выполняются в его окружении. Без Termux используется встроенное ядро.
- Android-экраны, кнопки, сообщения и уведомления переведены на русский и английский. Язык следует настройке оригинального OpenCode.

## Язык интерфейса

Выберите **Настройки → Общие → Язык** в OpenCode. Android-панель и дополнительные экраны подхватывают выбор без перезапуска ядра или перезагрузки текущего чата. Для русского используется русский перевод, для английского и остальных языков — английский. Все языки оригинального GUI остаются доступны.

Выбор сохраняется после закрытия приложения и применяется при переходе между встроенной средой и Termux. До первого выбора используется язык устройства (русский или английский). Каталог собственных текстов находится в `app/src/main/java/dev/pocketopencode/UiText.kt`; форматированные строки используют одинаковые нумерованные параметры в обоих переводах. Ответы модели и вывод внешних инструментов не переводятся.

## Начало работы

1. Установите APK на Android ARM64. Без Termux встроенное ядро запускается сразу. Если Termux установлен, выполните подключение через кнопку **Среда**; после него ядро запускается в Termux автоматически. Интерфейс OpenCode одинаков в обоих режимах.
2. Для нового проекта или ZIP нажмите **Android → Проекты**, создайте/импортируйте проект, затем **Открыть проект в OpenCode**. Существующую папку можно открыть и штатным выбором проекта OpenCode.
3. Подключите провайдера и выберите модель через штатный интерфейс OpenCode.
4. Напишите задачу в чате. Разрешения, ответы и изменения отображаются в родном GUI.
5. Экспорт ZIP и ручное управление ядром доступны по кнопке **Android**. Возврат к GUI — кнопкой «Назад» или «Открыть проект в OpenCode».

Для нового диалога нажмите постоянную кнопку **+ Чат** в верхней Android-панели. Она создаёт отдельную сессию в проекте, который сейчас открыт в GUI; старые сессии сохраняются. Кнопка доступна и тогда, когда пункт «Новая сессия» отсутствует в боковом меню. Если проект ещё не открыт, приложение предложит выбрать его.

## Выполнение команд

### Подключение Termux

Поддерживаются сборки с публичной службой `RUN_COMMAND`, например Termux 0.118.3 из [официальных GitHub Releases](https://github.com/termux/termux-app/releases). Проверяется наличие защищённой службы, а не только имя пакета. Google Play сборка `googleplay.2026.06.21` этой службы не содержит: приложение показывает причину несовместимости. Перед заменой источника подписи Termux сохраните его данные; Android не позволяет обычное обновление APK с другой подписью.

1. Откройте Termux один раз.
2. В Pocket OpenCode откройте **Среда → Скопировать команду настройки**, вставьте и выполните её в Termux. Команда включает `allow-external-apps=true`. После выдачи системного разрешения приложение само устанавливает недостающие curl, unzip, zip, Git, ripgrep и Node.js. Проверяется не только наличие, но и запуск утилит; при установке обновляется необходимая библиотека OpenSSL. Первая подготовка требует интернета.
3. Вернитесь и нажмите **Разрешить и подключить**. Android запросит разрешение выполнения команд в Termux. При отказе его можно выдать в дополнительных разрешениях Pocket OpenCode.

Настройка использует [официальный RUN_COMMAND API](https://github.com/termux/termux-app/wiki/RUN_COMMAND-Intent). Ядро OpenCode и Bun передаются локально из APK в `~/.local/share/pocket-opencode/`, без отдельной установки OpenCode. Git, Node.js, пакеты и shell берутся из Termux. Существующий `opencode` в PATH не заменяется. Ядро использует стандартные HOME и конфигурацию OpenCode в Termux.

Режимы: **Автоматически** (по умолчанию), **Только Termux**, **Встроенная среда**. Установленный, но неподключённый Termux вызывает ошибку настройки; скрытого переключения к другому окружению нет. Переключение останавливает текущий сеанс ядра. Долгие команды перед переключением следует завершить.

В режиме Termux кнопка **Android** открывает создание/клонирование проекта, импорт/экспорт ZIP и ручной запуск команд в Termux. Новые проекты размещаются в `~/pocket-projects`. Существующую папку можно открыть в родном GUI. Файлы встроенного проекта можно **скопировать** в Termux отдельной кнопкой; существующие папки не перезаписываются. Это разовое копирование, не двусторонняя синхронизация. История чатов и ключи автоматически не переносятся; они остаются в исходной среде.

Обмен файлами идёт через временный сервер только на 127.0.0.1 со случайным токеном. Импорт проверяет пути и лимиты ZIP до передачи. Ядро в Termux работает, пока действует локальное подключение: при остановке Pocket OpenCode его дочерний процесс завершается. Другие процессы Termux не останавливаются.

### Встроенная среда

```sh
git --version
node --version
bun --version
node src/main.js
node "$NPM_CLI" install --ignore-scripts
```

Android ограничивает запуск исполняемых файлов из доступных для записи папок. Поэтому встроенные ELF-файлы устанавливаются Android из `lib/arm64-v8a` внутри APK; в рабочем каталоге находятся только ссылки на них. JS и shell-скрипты нужно запускать через интерпретатор. Загружаемые нативные расширения, LSP, `node-gyp`, Docker и произвольные настольные сборочные цепочки не входят в поддерживаемый набор первой версии.

## Данные и безопасность

OpenCode слушает только loopback и защищён случайным паролем; пароль сервера зашифрован Android Keystore. Ключи провайдеров сохраняет штатный OpenCode в приватном каталоге приложения. Это не отдельное шифрование файла ключей. Android backup отключён. Импорт ZIP проверяет выход за пределы проекта, число файлов и размер распаковки. Данные проектов и диалогов переживают перезапуск приложения; удаление приложения удаляет его приватные данные — перед этим экспортируйте проекты.

Сервис показывает уведомление во время работы. Android всё равно может завершить процесс при нехватке ресурсов; незавершённые команды не восстанавливаются автоматически. Публикация в Google Play в этот проект не входит.

## Сборка на Windows

Нужны Node.js, curl, tar, JDK 21+ и Android SDK (platform 36, build-tools 36.0.0). Gradle wrapper включён.

```powershell
node scripts/prepare-runtime.mjs C:/path/to/runtime-cache
# Укажите sdk.dir в local.properties либо ANDROID_HOME в окружении.
./gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

`prepare-runtime.mjs` проверяет SHA-256 исходных бинарных архивов и извлекает модульный граф OpenCode из закреплённого артефакта. Старый Bun из этого артефакта **не используется**: JavaScript выполняется официальным Bun Android. `extract-opencode.mjs` переносит виртуальные пути модулей в каталог приложения. Семантика ядра не переписывается.

Нативные файлы и npm уже подготовлены в этой копии проекта; `.gitignore` исключает их для будущего Git-репозитория. Сведения о версиях и контрольных суммах — в `app/src/main/assets/runtime/sources.json`.

Архив `PocketOpenCode-source.zip` содержит исходники без сгенерированных бинарных файлов, SDK и Gradle-кеша. Перед сборкой из архива выполните `prepare-runtime.mjs`; версии и хеши пакетов закреплены в `runtime.lock.json`.

Это версия **0.4.9-alpha**, подписанная отладочным ключом для установки вручную. Встроенные плагины авторизации включены в обоих режимах. В OpenAI доступны ChatGPT Pro/Plus (browser), ChatGPT Pro/Plus (headless, вход по коду) и API-ключ. Наличие этих пунктов проверено на realme C75 в режиме Termux; полный вход в аккаунт через OAuth пока не проверен.

Извлечение ядра также восстанавливает импорты JS-модулей, экспортирующих пути к WASM. Атрибут `type: "wasm"` у такого JS-модуля в обычном Bun заставлял tree-sitter читать JavaScript вместо бинарного парсера; версия 0.2.2 устраняет эту ошибку загрузки. Разбор команд и запросы разрешений `bash` сохранены.

### Родной GUI

Ядро и готовый официальный GUI извлекаются из одного закреплённого релиза OpenCode 1.18.31 командой `prepare-runtime.mjs`. Отдельная сборка интерфейса не нужна. SHA-256 архива проверяется перед извлечением; `extract-webui.mjs` сохраняет исходные байты веб-ресурсов. Библиотеки совместимости Android берутся отдельно из закреплённого архива guysoft; старое ядро из него не используется.

Bun запускает извлечённое ядро с `--no-install`, чтобы не пытаться автоматически устанавливать необязательные нативные зависимости при импорте. Установка плагинов самим OpenCode остаётся отдельным механизмом.

## Проверки

```powershell
./gradlew.bat :app:testDebugUnitTest :app:assembleDebugAndroidTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w dev.pocketopencode.test/androidx.test.runner.AndroidJUnitRunner
```

Инструментальный тест запускает настоящее встроенное ядро, проверяет утилиты, создаёт сессию, выполняет shell-команду и проверяет историю после перезапуска. Для него не нужен ключ модели и не расходуются платные API-запросы. Фактические результаты проверки находятся в `VALIDATION.md`.

## Embedded Python (0.4.9)

Python 3.14.6 and pip 26.2.1 are available as `python`, `python3`, `pip` and `pip3`. Run Python entry-point scripts with `python script.py` or `python -m package`; Android does not execute scripts directly from writable app storage. Pure Python dependencies can be installed with `python -m pip install package`. Third-party native extensions may require unavailable Android builds or compilers.

The build pins Python dependencies in `runtime.lock.json` (`pythonPackages`). `scripts/prepare-runtime.mjs` includes `scripts/prepare-python.mjs`; to update an already prepared runtime, run `node scripts/prepare-python.mjs <cache>` and rebuild the APK.
