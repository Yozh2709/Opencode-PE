### Changes

- The installed app is now named **Opencode**. The GitHub project remains **Opencode-PE**.
- Uses the original OpenCode favicon artwork in an adaptive Android launcher icon.
- Adds **Settings → Updates** and an Updates button on the native Runtime screen, available even if the core cannot start.
- Checks GitHub Releases automatically at launch, at most once per day. Automatic checks can be disabled. Includes alpha releases and only offers newer versions with a completed ARM64 APK upload.
- Download opens the APK in your browser; installation stays under your control. The package ID and signing key are unchanged, so existing projects and chats are preserved when updating.

The Android 11 close_range compatibility fix from 0.4.12 is included.
