**Phone control.** The OpenCode agent can now operate the phone when you ask it to: read the screen, take screenshots, tap, type, scroll, swipe, press system keys and open apps. Turn it on in Settings → Runtime → Phone control (Android Accessibility → Opencode phone control). It works as a local MCP server inside the app, is registered with OpenCode automatically in both embedded and Termux modes, and is only reachable from the device with a private token.

**Faster interface.**
- Opening the app from the notification or launcher returns to the same screen instead of stacking a new copy of it.
- Returning to the app within 10 minutes no longer reloads the whole page.
- New chat opens instantly, without reloading the page, so the model selector is available right away.

**Fixes.** Attaching an image in chat no longer reloads the page and loses the picked file.
