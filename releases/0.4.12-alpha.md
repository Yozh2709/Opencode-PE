### Changes

- Added a bundled fallback for Bun's `close_range` calls on Android versions that terminate them with `SIGSYS` / `Bad system call`. Applied to both embedded and Termux backends; Bun stays at 1.4.2.
- Added startup diagnostics and a copy button directly to the Runtime screen, accessible even when OpenCode cannot start.
- Updated the Termux runtime payload automatically; existing projects, credentials and chats are preserved.

The Linux seccomp regression reproduces the original crash without the compatibility library and passes with it, including descriptor cleanup and child execution. APK build, JVM tests and lint passed. Confirmation on the reported Tecno Spark 8C / Android 11 device is still pending.

Install the APK over the previous alpha. No additional ZIP or manual command is required for this update.
